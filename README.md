# K-Nearest-Neighbors-KNN-Classification
# Task 11: K-Nearest Neighbors Classification

## Objective
To implement K-Nearest Neighbors classification using Python and Scikit-learn.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Seaborn
- Matplotlib

## Dataset
Social Network Ads Dataset

## Steps
1. Loaded the dataset
2. Selected features and target
3. Applied train-test split
4. Performed feature scaling using StandardScaler
5. Trained KNN classifier
6. Used Elbow Method to choose optimal K
7. Evaluated model using accuracy, confusion matrix, classification report, and ROC curve

## Output
The KNN model successfully classified whether a user purchased a product or not.

## Final Outcome
Understood distance-based classification and hyperparameter tuning using K value.
